# 0.0.14：输入框里的模型展示——读数挪到模型旁边、倍率与徽标统一

> 你圈的是输入框右侧的模型选择器。那块界面**是宿主画的**，插件改不了它的样式，
> 但插件决定它显示什么：模型名、说明、徽标，以及能往它旁边插一个读数。
> 这一版把这几件事都做了；顺带查出一个倍率解析的真 bug。

## 1. 账号 + 智点读数，挪到模型选择器紧前面

以前读数在 `conversation.input.left`（贴着「完全权限」），而且只显示
`灵犀 · 3,000` —— 不说是哪个账号。

现在：

1. 槽位改到 `conversation.input.right`，宿主把它渲染在**模型选择器紧前面**；
2. 读数同时显示当前账号与智点：`895137935 · 3,000 智点`；
3. 账号取 `current`（真在出账的那个），不是 `selected`（用户点选的那个）——
   账号池挑号之后两者可能不是一个，而这个读数要回答「这条消息由谁出账」。

为什么不能继续放左边：左边贴着「完全权限」下拉，两者都可点，
伸手去点权限会误触读数。`dsh-connect-workbuddy` 和 `dsh-connect-trae`
都因为这个问题把读数从 left 挪到了 right，这里跟着改。

为什么账号名要缩短：上游账号名就是 `uid-895137935`，没有昵称。
去掉 `uid-` 前缀、超长省略中间，避免把模型选择器挤开。

## 2. 倍率解析的真 bug：`Pro 模式` 的倍率是字符串「模式」

`fromRawEntry` 里原来写的是：

```ts
multiplier: normalizeTilde(stringOr(raw.multiplier, kind === 'plan' ? '模式' : ''))
```

`plan_pro` / `plan_max` 上游不给倍率，于是回落成了字面量「模式」。
结果插件卡片那两个模式的倍率列显示 **「倍率 模式」** —— 把名称里的字当成了数值。

现在两个 kind 都回落到空串：没有倍率就是没有，界面自然不渲染那一列。

## 3. 下拉说明统一成「倍率在前」

以前：

```ts
description: model.description ?? (multiplier === '' ? undefined : `倍率 ${multiplier}`)
```

只有上游**没给**说明时才写倍率。于是同一个下拉里两种格式并存：
有的行是「倍率 ~0.12x」，有的行是一句宣传语、倍率消失——
而倍率恰恰是选模型时要比的那个数。

现在每行都是 `倍率 x · 上游说明`：倍率一定在最前（没有倍率就不写），
后面才是上游文案；两段都没有就省略这一行，不塞空串占位。

## 4. 徽标按语言给说法

宿主的徽标字段是 `LocalizedText`（一个字符串，或按语言分开的翻译）。以前直接传
中文串，英文界面就原样显示「正式版」。现在：

| 上游原文 | 中文界面 | 英文界面 |
| --- | --- | --- |
| `NEW` | NEW | NEW |
| `正式版` | 正式版 | GA |
| `首发接入` | 首发接入 | Launch |
| 其它 | 原文 | 原文 |

认不出的文案原样透传 —— 不知道含义就翻译，那是在编。

## 没做的

**把倍率/徽标画进模型名字本身**：宿主的模型选择器把小标签渲染在名字旁边
（`LlmModelInfo.badge`），这是它的职责；插件往名字里塞符号，会变成
「DeepSeek V4.1 Flash ~0.12x NEW」这种一行字，选择器里反而更难读。
